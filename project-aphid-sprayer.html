On-robot perception · Spraying hardware

Real-Time Vision-Guided Precision Sprayer

2025 – Present Kansas State University · FarmsLab Perception + hardware lead

Overview

A real-time pest-detection and precision-spraying system that runs on the skid-steer platform. Stereo cameras detect aphids, a lightweight 3D localization step estimates where each one sits relative to the robot, and a MOSFET-driven solenoid array fires the nozzles that correspond to those positions — just the nozzles that need to fire, just when they need to fire.

What I did

  • Transformer-based aphid detection (RT-DETRv2) running in real time on an embedded GPU with TensorRT.
  • Stereo 3D localization of detections plus an EKF to stabilize pest position estimates relative to the cameras.
  • MOSFET-based solenoid driver stack for targeted spraying, with a secondary I²C path kept as a hardware-debuggable fallback to the OEM CAN sprayer.
  • Dataset curation and augmentation for the aphid class; training in PyTorch and export through ONNX for deployment.
  • End-to-end ROS2 pipeline: perception, detection → 3D pose bridge, nozzle controller, and sprayer driver nodes.
